# Sales Analyzer — практическая работа модуля 10

Консольное приложение на Go для анализа шести продаж из задания. Пользовательский ввод и меню не требуются: программа автоматически выводит продажи, суммы, статистику и результат скидки.

## Запуск

Нужны Go 1.20 или новее и Visual Studio 2022/2026 с рабочей нагрузкой «Разработка классических приложений на C++», как для модуля 09. Нагрузка нужна для проекта Makefile; исходники программы написаны на Go.

Распакуйте архив, откройте **SalesAnalyzer.sln**, выберите **Debug | x64** и нажмите **Ctrl+F5**. После установки Go перезапустите Visual Studio.

Альтернатива: в терминале в папке с `go.mod` выполните `go run .`. Сторонние библиотеки и база данных не нужны.

## Результаты и демонстрация

- Шесть записей, продано **25 единиц**.
- Общая выручка: **1 515 000 тг**.
- Средняя сумма одной записи: **252 500 тг** — выручка делится на число записей, а не на число единиц товара.
- Самый продаваемый товар: **Мышь — 10 шт.**
- Выручка по категориям: **Электроника — 1 305 000 тг**, **Аксессуары — 210 000 тг**.
- После скидки цена первой продажи ноутбука меняется с **350 000** на **315 000 тг**. Выручка становится **1 445 000 тг**.

Покажите отчёт, затем вызов `ApplyDiscount(&sales[0], discounts[1])`: процент берётся из второго элемента массива, а указатель позволяет изменить первую запись с двумя ноутбуками. Поэтому выручка уменьшается на **70 000 тг**; шестая запись с одним ноутбуком не меняется.

## Структура

- `main.go` — вывод отчёта, массив скидок `[3]float64{5, 10, 15}`, применение скидки.
- `sales.go` — структура Sale, исходные данные и функции CalculateRevenue, GetTopProduct, RevenueByCategory, ApplyDiscount и другие расчёты.
- `go.mod` — модуль Go; `.sln` и `.vcxproj` — сборка Go из Visual Studio.

Продажи хранятся в `[]Sale`. Для самого продаваемого товара используется `map[string]int`: обе продажи ноутбука объединяются по названию и дают 3 единицы. Выручка категорий собирается в `map[string]float64`. При равенстве количества у нескольких товаров выбирается первое встретившееся название. Все результаты вычисляются, а не записаны готовыми числами в коде.
